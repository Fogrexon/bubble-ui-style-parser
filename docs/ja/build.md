# Bubble UI Style Parser - ビルド手順

このドキュメントでは、Bubble UI Style Parser ライブラリの開発環境をセットアップし、ビルドするために必要な手順を説明します。

## 前提条件

開始する前に、システムに以下のものがインストールされていることを確認してください。

-   **Node.js**: 最新の LTS バージョンを使用することをお勧めします。[nodejs.org](https://nodejs.org/) からダウンロードできます。
-   **npm** (Node Package Manager): これは通常、Node.js と一緒にインストールされます。

## 開始方法

プロジェクトを起動して実行するには、以下の手順に従ってください。

1.  **リポジトリのクローン (まだ行っていない場合):**
    ソースを直接操作する場合は、プロジェクトファイルがあることを確認してください。

2.  **依存関係のインストール:**
    ターミナルでプロジェクトのルートディレクトリに移動し、npm を使用して必要な依存関係をインストールします。

    ```bash
    npm install
    ```

    このコマンドは `package.json` ファイルを読み込み、必要なすべてのパッケージをダウンロードします。

3.  **ライブラリのビルド:**
    依存関係がインストールされたら、ライブラリをビルドできます。このプロジェクトはビルドツールとして [Vite](https://vitejs.dev/) を使用しており、[TypeScript](https://www.typescriptlang.org/) で記述されています。

    プロジェクトをビルドするには、次のコマンドを実行します。

    ```bash
    npm run build
    ```

    このコマンドは `package.json` で定義されているビルドスクリプトを実行し、TypeScript ソースコード (`src/` ディレクトリ) をコンパイルして、コンパイル済みの JavaScript ファイルを `dist/` ディレクトリに出力します。`--emptyOutDir` フラグは、新しいビルドの前に出力ディレクトリがクリーンアップされることを保証します。

## 開発コマンド

-   **テストの実行:** 単体テストを実行するには、以下を使用します。
    ```bash
    npm test
    ```
    単一の非対話型テスト実行の場合:
    ```bash
    npm run test:once
    ```
-   **Linting:** リンターを実行してコードスタイルの問題を確認するには:
    ```bash
    npm run lint
    ```
    リンティングの問題を自動的に修正するには (可能な場合):
    ```bash
    npm run lint:fix
    ```

これらの手順に従うことで、Bubble UI Style Parser ライブラリのビルド済みバージョンが作成され、開発の準備が整います。
