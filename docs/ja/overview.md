# Bubble UI Style Parser - 概要

Bubble UI Style Parser は、スタイル定義を解析して抽象構文木（AST）に変換するために設計された TypeScript ライブラリです。この AST 表現は、静的解析、コード生成、UI フレームワーク内での動的なスタイル設定など、様々な目的に利用できます。

## 主要機能

-   **モジュラー解析:** このライブラリはモジュラー設計を採用しており、トークン化、アトミックトークン解析、文法ルールの適用を分離しています。
-   **抽象構文木（AST）の生成:** 生のスタイル入力から構造化された AST を生成し、スタイル定義をプログラムで簡単に扱い、解析できるようにします。
-   **カスタマイズ可能な文法ルール:** ユーザーはカスタム文法ルールを定義・適用して、様々なスタイル構文を解析できます。これにより、異なるプロジェクトやデザインシステムに柔軟に採用できます。
-   **アトミックトークン解析:** 専用のパーサーがアトミックなスタイル要素（例：数値、文字列、単位、色）を処理し、個々のスタイル値の堅牢で正確な解析を保証します。

## アーキテクチャのハイライト

主要なアーキテクチャは、以下の主要コンポーネントを中心に構築されています。

-   **Tokenizer:** 生の入力文字列を意味のあるトークンのストリームに分解します。
-   **Atomic Token Parsers:** 個々のトークンタイプ（例：`parseNumericValue`、`parseStringValue`、`parseColorValue`）に特化したパーサー群です。
-   **Grammar Rules (`GrammarRule`):** 異なるスタイル要素間の階層構造と関係を定義し、解析プロセスをガイドします。
-   **Parser Generator (`ParserGenerator`):** 定義された文法ルールをトークンストリームに適用し、最終的な AST を構築することで、解析プロセスを統括します。

このライブラリは、動的なスタイル処理、テーマ管理、UI スタイリングのためのカスタム DSL（ドメイン固有言語）を必要とするプロジェクトに最適です。
